홈페이지를 다 읽고 맨 아래까지 내려오는 손님은 많지 않습니다. 문의하고 싶어진 그 순간, 바로 눈앞에 버튼이 있어야 합니다.

문의 버튼 자리 공식
첫 화면 · 중간 · 맨 아래
여기에 휴대폰 화면 아래쪽에 늘 떠 있는 카카오톡·전화 버튼을 더하면 좋습니다.

자리별로 이렇게

① 첫 화면 바로 문의할 손님

제목 바로 아래에 버튼 하나예: "무료 견적 받기", "체험 수업 신청"

버튼은 하나만 크게. 버튼이 여러 개면 손님이 고민하다 나갑니다.

② 중간 더 알아보는 손님

서비스 소개·작업 사례가 끝나는 곳마다예: 작업 전후 사진 바로 아래 "우리 집도 견적 받아보기"

③ 맨 아래 끝까지 본 손님

자주 묻는 질문 다음, 연락처와 함께예: 문의 폼 + 전화번호 + 카카오톡 버튼

④ 늘 떠 있는 버튼 휴대폰

화면 오른쪽 아래 카카오톡 또는 전화 버튼홈페이지 빌더의 플로팅(고정) 버튼 기능을 쓰면 됩니다

문의 폼은 짧게

  • 칸은 이름 · 연락처 · 문의 내용 3개면 충분합니다
  • 주소, 예산처럼 꼭 필요하지 않은 칸은 상담할 때 물어보세요
  • 개인정보 수집 동의는 꼭 넣되, 한 줄로 간단히
  • 보낸 뒤 "언제까지 연락드릴게요" 안내를 띄우세요
  • 폼 대신 카카오톡을 선호하는 손님을 위해 카톡 버튼도 같이 두세요
